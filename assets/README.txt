Drop official brand logos in this folder to replace the built-in ones.

    assets/logo.png        The app's own logo (window + taskbar + splash)
    assets/yt.png          YouTube / YT Music
    assets/spotify.png     Spotify
    assets/soundcloud.png  SoundCloud

Any of these extensions work: .png  .svg  .jpg  .jpeg  .webp
Square and transparent, at least 128x128, looks best.

logo.png is the app's own branding. When present it replaces the window,
taskbar and splash-screen icon; when absent the app falls back to the
selected service's mark, exactly as before.

If a file is present it is used automatically - no need to change any code
or restart anything else. Delete the file to go back to the built-in icon.

The built-in icons are original simplified marks drawn by the app itself,
so there is nothing to download and no licensing to worry about. Official
logos are trademarks of their owners and are fine for personal use only.
